# Molecular Spectroscopy Virtual Laboratory

## 26-compound teaching spectrum library
Select one of 26 built-in compounds. The selected library entry supplies its compound name, SMILES, approximate IR reference-band profile, UV-visible teaching profile and IR assignments. The selected compound updates the IR and UV pages automatically. The previous free-form New Compound / New SMILES workflow is replaced by this curated library selector.

The collection includes aromatic compounds, alcohols, carbonyl compounds, nitriles, inorganic molecules and simple hydrocarbons. Peak centres and line shapes are approximate teaching references. They are not experimental measurements, validated spectra, or DFT/TDDFT-calculated normal modes. Actual UV-visible band positions and intensities are strongly dependent on solvent, phase, concentration and method.

## Deploy
Replace the existing project files in the repository with these files and commit to `main`. Import/redeploy through Vercel as before.
